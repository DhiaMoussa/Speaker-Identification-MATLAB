
# Speaker Identification System – MATLAB

## Présentation du projet

Développement d'un système d'identification de
locuteurs à partir de l'analyse des signaux vocaux
avec MATLAB.

Le système exploite les coefficients MFCC et la
distance euclidienne pour comparer des signatures
vocales et identifier les locuteurs.

## Objectifs

- Analyser des enregistrements vocaux.
- Extraire les caractéristiques acoustiques.
- Construire des signatures vocales de référence.
- Comparer les signatures entre elles.
- Identifier les locuteurs connus et inconnus.

## Réalisations techniques

- Acquisition des signaux vocaux.
- Préparation et traitement des enregistrements.
- Extraction des coefficients MFCC.
- Construction des signatures vocales.
- Calcul de la distance euclidienne.
- Utilisation d'un seuil de décision.
- Classification des voix.

## Technologies utilisées

- MATLAB
- Traitement numérique du signal
- MFCC
- Distance euclidienne
- Analyse acoustique
- Reconnaissance de formes

## Compétences développées

- Traitement numérique du signal
- Analyse de données
- Extraction de caractéristiques
- Programmation MATLAB
- Reconnaissance vocale
- Méthodes de classification

## Applications

- Identification de locuteurs
- Analyse de signaux vocaux
- Reconnaissance automatique de formes

# Speaker-Identification-MATLAB
Développement d'un système d'identification de locuteurs à l'aide de MATLAB et de techniques de traitement numérique du signal vocal. Extraction des coefficients MFCC, construction de signatures vocales et comparaison par distance euclidienne. Utilisation d'un seuil de décision pour distinguer les locuteurs enregistrés des voix inconnues.
